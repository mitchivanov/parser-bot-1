# Telegram Parser Bot

Бот для парсинга сообщений из Telegram каналов с фильтрацией по ключевым словам и отправкой результатов в целевые каналы.

## Функциональность

- Чтение сообщений из указанных каналов
- Фильтрация по ключевым словам (включение/исключение)
- Пересылка сообщений в целевые каналы
- Поддержка медиа-контента (фото, видео, аудио, документы, стикеры, опросы)
- Обработка альбомов (группы медиа-файлов)
- Фильтрация и замена Telegram-ссылок
- Адаптивная настройка интервалов проверки каналов в зависимости от их активности
- Сохранение состояния для корректного возобновления работы после перезапуска

## Требования

- Python 3.7+
- Telethon
- Aiogram 3.x
- Docker (для запуска в контейнере)

## Установка и запуск

### Запуск с использованием Docker Compose (рекомендуется)

1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd telegram-parser-bot
```

2. Создать файл конфигурации окружения из примера:
```bash
cp config.env.example config.env
```

3. Отредактировать файл config.env, добавив необходимые параметры:
```
# Telegram API
TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_PHONE=your_phone_number

# Bot settings
PARSE_INTERVAL=60
TZ=Europe/Moscow
```

4. Отредактировать файл источников (sources.txt), добавив нужные каналы (по одному на строку):
```
@channel1
@channel2
https://t.me/channel3
```

5. Убедиться, что файл конфигурации (bot/config.json) настроен правильно:
```json
{
  "telegram": {
    "api_id": 12345,
    "api_hash": "your_api_hash",
    "bot_token": "your_bot_token",
    "phone": "your_phone_number"
  },
  "channels": {
    "source": [-1234567890],
    "target": [-9876543210]
  },
  "filters": {
    "include": ["важно", "срочно"],
    "exclude": ["спам", "реклама"]
  },
  "settings": {
    "admins": [123456789],
    "rate_limit": {
      "max_requests": 5,
      "period_seconds": 60
    },
    "parse_interval": 60
  },
  "use_sources_file": true,
  "sources_file": "sources.txt"
}
```

6. Запустить с помощью Docker Compose:
```bash
docker-compose up -d
```

### Авторизация при первом запуске

При первом запуске потребуется авторизовать Telegram аккаунт:

1. Запустите приложение в режиме просмотра логов:
```bash
docker-compose up
```

2. Бот отправит запрос кода подтверждения в Telegram всем администраторам, указанным в настройках.

3. Получите SMS-код на телефон, указанный в настройках (TELEGRAM_PHONE), и отправьте этот код боту.

4. Если включена двухфакторная аутентификация, бот запросит пароль. Отправьте пароль боту.

5. После успешной авторизации сессия будет сохранена в директории `sessions/` и при последующих запусках авторизация не потребуется.

6. Когда авторизация завершена, можно перевести бота в фоновый режим:
```bash
docker-compose down
docker-compose up -d
```

### Просмотр логов
Для просмотра логов и отслеживания процесса авторизации используйте:
```bash
docker-compose logs -f
```

### Запуск без Docker

1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd telegram-parser-bot
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Отредактировать конфигурационные файлы (см. выше)

4. Запустить бота:
```bash
python -m bot.main
```

## Команды бота

- `/start` - Запуск бота
- `/help` - Справка по командам
- `/stats` - Статистика работы (доступно только администраторам)
- `/status <channel_id>` - Проверка статуса конкретного канала (доступно только администраторам)

## Структура проекта

```
/bot
  ├── __init__.py
  ├── config.py        - Конфигурация и константы
  ├── config.json      - Файл конфигурации
  ├── main.py          - Точка входа
  ├── parser.py        - Основной парсер
  ├── /data            - Модули для работы с данными
  │   └── storage.py   - Хранилище состояния
  ├── /handlers        - Обработчики команд и сообщений
  │   ├── commands.py  - Обработчики команд
  │   └── message_handler.py - Обработчики сообщений
  ├── /middleware      - Промежуточное ПО
  │   └── rate_limit.py - Ограничение частоты запросов
  └── /utils           - Вспомогательные модули
      ├── channel_utils.py - Утилиты для работы с каналами
      ├── monitoring.py - Мониторинг состояния бота
      └── retry.py     - Механизм повторных попыток
/sessions              - Директория для сессий Telethon
/sources.txt           - Файл со списком источников
/docker-compose.yml    - Конфигурация Docker Compose
/Dockerfile            - Файл сборки Docker образа
/entrypoint.sh         - Точка входа для Docker контейнера
/requirements.txt      - Зависимости Python
/config.env            - Переменные окружения для Docker
```

## Особенности

- Бот автоматически адаптирует интервалы проверки каналов в зависимости от их активности
